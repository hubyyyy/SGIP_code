Contents of SGIP_code.zip
=========================

Purpose
-------
This is the code and figure reproduction package for "A Stochastic Genetic
Interacting Particle Method for Reaction-Diffusion-Advection Equations"
(https://arxiv.org/abs/2511.12275). The numerical examples have no external
input data; all density fields are generated by the included code.

Reproducibility documentation
-----------------------------
README.md
    Detailed environment setup, figure coverage, paper-scale commands,
    resource requirements, output descriptions, and numerical conventions.

paper_experiments.json
    Machine-readable map from Figures 1--15 to equations, initial conditions,
    SGIP settings, FDM settings, and reproduction drivers.

reference_outputs/
    Figure panels used in the submitted manuscript, included as visual targets
    for reproduction checks. They are not solver inputs. README.txt explains
    the role of these files.

CONTENTS.txt
    This itemized archive index.

    Citation metadata for the reproducibility package.

Environment files
-----------------
requirements.txt
    Host-side data preparation and plotting dependencies: NumPy and Matplotlib.

requirements-gpu-cu11.txt
requirements-gpu-cu12.txt
    CUDA-specific CuPy requirements. Install only the file matching the local
    CUDA major version.

Paper reproduction drivers
--------------------------
reproduce_1d.py
    Reproduces Figures 1--6, including the three reaction laws, front-position
    plots, and the two bistable initial conditions.

reproduce_2d.py
    Reproduces Figures 7--10 for no flow, shear, cellular, and cat's-eye flow.

reproduce_3d.py
    Reproduces Figures 11--15 for ABC flow, three diffusion coefficients, and
    three reaction laws.

reproduce_paper.py
    Runs all three reproduction drivers in sequence. It provides quick and
    paper presets and guards the largest FDM grids against accidental launch.

Numerical implementation
------------------------
sgip_core.py
    Shared configuration, result types, and snapshot-time selection.

sgip_gpu.py
    CuPy/CUDA implementation of the SGIP time-stepping operations.

sgip_models.py
    Initial conditions and the shear, cellular, cat's-eye, and ABC velocity
    fields. GPU reaction updates are implemented in sgip_gpu.py.

reference_fdm.py
    CUDA one-dimensional IMEX FDM reference solver.

reference_fdm_nd.py
    CUDA two- and three-dimensional IMEX FDM reference solver.

sgip_io.py
    Output, plotting, and timing-summary utilities.

cli_common.py
    Shared command-line arguments and CUDA availability checks.

Validation and packaging
------------------------
test_smoke.py
    Lightweight CUDA SGIP/FDM tests and device-independent package checks.

make_release.py
    Builds a clean SGIP_code.zip archive and its SHA-256 checksum from
    RELEASE_FILES.txt.

RELEASE_FILES.txt
    Authoritative manifest for the release archive.

.gitignore
    Excludes generated output and local Python cache files.
