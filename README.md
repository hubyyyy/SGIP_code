# SGIP_code

This repository accompanies the manuscript **A Stochastic Genetic Interacting
Particle Method for Reaction-Diffusion-Advection Equations** by Boyi Hu,
Zhongjian Wang, Jack Xin, and Zhiwen Zhang. It contains the code and figure
reproduction materials for the manuscript.

Paper: <https://arxiv.org/abs/2511.12275>

The repository contains the SGIP implementation, the finite-difference reference
implementation, all parameter settings needed for Figures 1--15, scripts that
generate those results, and reference copies of the figures used in the
manuscript. The examples use no external observational data: all numerical
data are generated by the included programs.

The complete, machine-readable parameter record is in
`paper_experiments.json`. The files under `reference_outputs/` are the figure
panels used in the submitted manuscript and provide a visual target for a
reproduction run. They are not inputs to the solvers.

## Software environment

Reproducing the numerical results requires Python 3.9 or later and an
NVIDIA CUDA GPU. Install the host-side plotting dependencies first:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Check the installed driver and toolkit:

```bash
nvidia-smi
nvcc --version
```

Then install exactly one matching CuPy package. For CUDA 12:

```bash
python -m pip install -r requirements-gpu-cu12.txt
```

For CUDA 11:

```bash
python -m pip install -r requirements-gpu-cu11.txt
```

Verify that CuPy sees the device:

```bash
python -c "import cupy as cp; print(cp.__version__, cp.cuda.runtime.getDeviceCount(), cp.cuda.runtime.getDeviceProperties(0)['name'])"
```

The manuscript calculations were performed on the HKU HPC2021 system with
an NVIDIA Tesla V100 32 GB SXM2 GPU.
Different GPUs and library versions can change timings and random samples.

## Installation check

Run the smoke tests and a reduced reproduction from the repository directory
on a CUDA machine:

```bash
python test_smoke.py
python reproduce_paper.py --preset quick --quiet
```

The `quick` preset uses reduced final times, particle counts, bins, and FDM
grids. It checks every code path and produces the same types of files as the
paper run, but it is not a numerical reproduction of the published figures.

## Paper-scale reproduction

The following commands use the parameters reported in the manuscript:

```bash
python reproduce_1d.py --preset paper

python reproduce_2d.py --preset paper \
  --allow-large-fdm

python reproduce_3d.py --preset paper \
  --allow-large-fdm
```

To run all three drivers in sequence:

```bash
python reproduce_paper.py --preset paper \
  --allow-large-fdm
```

Add `--save-data` to the 2D, 3D, or combined command to retain the generated
density arrays as compressed NumPy files. This can require several gigabytes
for the finest FDM grids. Figures and JSON summaries are always saved.

Individual expensive figures can be run separately, for example:

```bash
python reproduce_2d.py --figures 8 --preset paper --allow-large-fdm

python reproduce_3d.py --figures 11 --preset paper --allow-large-fdm
```

The paper-scale 2D FDM grid contains `12000^2` cells. The 3D FDM grids contain
`200^3` cells for Figure 11 and `300^3` cells for Figure 12. Figure 13 reports
only SGIP because the corresponding `400^3` FDM calculation was identified in
the manuscript as computationally prohibitive. The large-grid guard prevents
these jobs from being launched accidentally.

## Numerical conventions

The numerical section writes the equation as

```text
u_t = D Delta(u) + w dot grad(u) + r(u).
```

The particle drift is therefore `-w`. SGIP uses Euler--Maruyama for the
advection-diffusion step, bin-based reaction updates, and the retain/clone
resampling rule described in the manuscript. The FDM reference uses
first-order upwinding for advection, centered finite differences with an
implicit DCT solve for diffusion, pointwise reaction updates, and homogeneous
Neumann conditions at the artificial outer boundary.

All drivers use a fixed base seed (`2025`). Repeated stochastic runs should
reproduce the same front locations and resolved structures up to the sampling
variation of the particle method.
The deterministic FDM output should agree to floating-point roundoff for a
fixed software environment.

## Outputs

Generated files are placed under `output/paper/` unless `--output-dir` is
given. Each driver writes:

- one PDF for each displayed panel;
- `summary.json` with the resolved parameters, backend, and elapsed times;
- optional `.npz` density fields when `--save-data` is supplied.

Compare generated panels with `reference_outputs/`. Exact pixel agreement is
not expected for SGIP because the calculation is stochastic and the plotting
library may differ. The qualitative front geometry, displayed cross-sections,
and SGIP/FDM agreement are the intended reproduction targets.

## Package map

- `sgip_core.py`: shared configuration and result types.
- `sgip_gpu.py`: CUDA SGIP implementation.
- `sgip_models.py`: initial conditions and velocity fields.
- `reference_fdm.py`: CUDA 1D FDM reference solver.
- `reference_fdm_nd.py`: CUDA 2D/3D IMEX FDM reference solver.
- `reproduce_1d.py`, `reproduce_2d.py`, `reproduce_3d.py`: paper drivers.
- `reproduce_paper.py`: all-figure orchestration command.
- `paper_experiments.json`: complete figure-to-parameter mapping.
- `reference_outputs/`: immutable visual outputs used in the manuscript.
- `test_smoke.py`: lightweight tests for SGIP, FDM, and manifest coverage.
- `CONTENTS.txt`: itemized archive index.
