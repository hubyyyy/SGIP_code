Reference outputs from the submitted manuscript
================================================

This directory contains the figure panels used in Figures 1--15 of the
manuscript. These files are included only as visual reference outputs for
reproduction checks. They are not read by the SGIP or FDM solvers.

The numerical problems do not use external input data. New density fields and
figures are generated by reproduce_1d.py, reproduce_2d.py, and
reproduce_3d.py. SGIP is stochastic, so newly generated panels need not agree
pixel by pixel with these files even when the recorded parameters are used.
